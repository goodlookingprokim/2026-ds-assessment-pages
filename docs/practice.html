파일 제출을
먼저 연습해요

내 Google 계정으로 로그인하고, 작은 파일 하나를 첨부해 제출 완료 화면까지 확인합니다.

연습 파일 받기 → 개인 계정 로그인 → 파일 첨부 → 제출 완료 확인
이 설문은 연습용입니다.

성적에 반영되지 않으며 여러 번 연습할 수 있습니다. 연습을 마쳐도 1차·2차 수행평가 제출이 완료되는 것은 아닙니다. 실제 과제는 각 안내 페이지의 제출 설문으로 내세요.

준비물은 두 가지예요

  • 본인이 사용할 수 있는 개인 Google 계정
  • 아래에서 내려받는 작은 연습 파일 1개

연습 파일에 이름·학번·사진·과제 내용을 넣지 않아도 됩니다. 파일 내용을 고칠 필요도 없습니다.

파일을 업로드하고 제출하면 Google 계정의 이름·이메일·프로필 사진이 자동으로 기록됩니다.

① 연습 파일 받기 (.txt)② 연습 설문 열기 ↗

설문은 새 탭에서 열립니다. 이 안내를 옆에 두고 차례대로 따라 하세요.

처음부터 차례대로 따라 하세요

  1. 연습 파일을 내려받아요

    위의 ① 연습 파일 받기를 누릅니다. 보통 컴퓨터의 다운로드 폴더에 upload-practice.txt가 저장됩니다. 저장 위치와 파일 이름을 확인하세요.

  2. 내 개인 Google 계정으로 로그인해요

    ② 연습 설문 열기를 누릅니다. 로그인 화면이 나오면 내 개인 Google 계정으로 로그인합니다. 친구·교사·공용 계정을 사용하지 마세요. 비밀번호는 설문 문항에 적지 않습니다.

  3. 설문에 표시된 계정을 확인해요

    설문 위쪽 이메일이 내 계정인지 확인합니다. 다른 사람의 계정이면 계정 전환을 눌러 내 계정으로 바꾸세요. 연습 별명은 선택 문항이며, 쓰고 싶으면 연습01처럼 적으면 됩니다.

  4. 파일을 선택하고 업로드해요

    파일 첨부 문항에서 파일 추가를 누릅니다. 업로드 → 찾아보기(Browse) 또는 파일 선택 버튼을 눌러 다운로드 폴더의 upload-practice.txt를 선택하세요. 파일을 고르면 업로드가 시작됩니다. 별도로 업로드 버튼이 보이면 누르세요. 업로드가 끝나고 설문지에 파일명이 나타날 때까지 기다립니다.

  5. 첨부한 파일 이름을 확인해요

    설문 문항 안에 upload-practice.txt가 표시되는지 확인합니다. 잘못 고른 파일이면 옆의 삭제 버튼으로 지운 뒤 다시 첨부하세요. 파일 이름이 보이면 제출 전 확인 문항에서 내 개인 Google 계정으로 로그인했고, 올린 파일명을 확인했습니다.에 체크합니다.

  6. 제출 버튼을 누르고 완료 화면을 확인해요

    맨 아래 제출을 누릅니다. 파일 제출 연습이 완료되었습니다.라는 안내가 나타나면 성공입니다. 파일 첨부만 하고 창을 닫으면 제출되지 않습니다.

막히면 여기부터 확인하세요

다른 사람의 이메일이 표시돼요.
설문 위쪽의 계정 전환을 누르세요. 여러 계정이 있으면 본인의 개인 계정을 선택한 뒤 표시된 이메일을 다시 확인합니다.
계정이 없거나 로그인할 수 없어요.
제출 마감 전에 교사에게 알려 도움을 받으세요. 다른 사람의 계정을 빌려서 제출하지 않습니다.
파일이 어디 있는지 모르겠어요.
다운로드 폴더에서 upload-practice.txt를 찾으세요. 없으면 이 페이지에서 연습 파일을 다시 받습니다.
업로드가 안 되거나 파일이 너무 크다고 해요.
연습 설문에는 파일 1개, 10MB 이하를 첨부합니다. 여기서 제공한 작은 .txt 파일을 고르고 업로드가 끝날 때까지 기다리세요. 인터넷 연결과 내 계정 로그인 상태도 확인합니다.
권한이 없다는 화면이 나와요.
개인 Google 계정으로 로그인했는지 확인합니다. 계속 막히면 오류 문구를 교사에게 보여 주세요.
제출 버튼을 눌러도 다음 화면으로 넘어가지 않아요.
빨간색으로 표시된 필수 문항을 확인하세요. 파일 첨부와 확인 체크를 마친 뒤 다시 제출합니다.

연습을 마쳤다면

  • 내 계정으로 로그인했다.
  • 설문 안에서 첨부한 파일 이름을 확인했다.
  • 제출 버튼을 누르고 접수 완료 화면을 확인했다.
