2. 내 자료로 바꾸기

바꿀 곳뜻운동 시간 예시
제목무엇을 알아볼까요?평일 운동 시간
항목이름이름들을 묶어 부르는 말요일
이름비교할 항목들월·화·수·목·금
숫자각 이름에 대응하는 값20·30·10·40·25
단위숫자의 단위분
자료설명가상 자료인지, 기록·출처는 무엇인지연습을 위해 만든 가상 운동 시간
처음이라면 · 자료 셀을 이렇게 바꿔 보세요
제목 = "평일 운동 시간"
항목이름 = "요일"
이름 = ["월", "화", "수", "목", "금"]

단위 = "분"

이 코드는 예시입니다. 내 주제와 자료로 바꾸세요. 글자는 따옴표로 묶고, 숫자 사이는 쉼표로 구분합니다.

이름과 숫자는 순서대로 한 쌍입니다. 월요일은 20분, 목요일은 40분입니다. 이름과 숫자의 개수를 같게 맞추고 같은 단위를 씁니다. 항목 5개는 예시이며 필수 개수가 아닙니다. 가상 자료는 가상이라고 적고, 가져온 자료는 출처를 적습니다.

바꾼 예시 파일 받기
운동 시간으로 바꾼 예시 보기 · 코드 펼치기

아래는 내려받는 예시 노트북의 주요 코드입니다. 내 자료 셀만 바꾸어 실행하세요.

1. 내 자료

# ★ 여기를 바꾸세요: 이 자료 셀 한 곳만 바꾸면 됩니다.
제목 = '평일 운동 시간'
항목이름 = '요일'
이름 = ['월', '화', '수', '목', '금']
숫자 = [20, 30, 10, 40, 25]
단위 = '분'
자료설명 = '가상 자료'
# 이름과 숫자의 개수는 같게 맞춥니다.

2. NumPy 계산

자료 = np.array(숫자)
합계 = np.sum(자료)
평균 = np.mean(자료)
print(제목, "—", 자료설명)
print("합계:", 합계, 단위)
print("평균:", 평균, 단위)

3. pandas 표

표 = pd.DataFrame({항목이름: 이름, "값(" + 단위 + ")": 자료})
display(표)

4. Matplotlib 그래프

plt.bar(이름, 자료)
plt.title(제목)
plt.xlabel(항목이름)
plt.ylabel(단위)
plt.show()

4. 파일과 일곱 답변 제출하기

① 결과 저장 → ② .ipynb 다운로드 → ③ 파일·답변 작성 → ④ 제출 완료 순서입니다.

① 실행 결과를 저장하고 파일 받기

  1. 수정 → 노트 설정(Edit → Notebook settings)의 ‘저장할 때 코드 셀 출력 생략’이 켜져 있다면 끕니다. 그래야 실행 결과도 파일에 저장됩니다.
  2. 파일 → 저장을 누릅니다. Windows는 Ctrl + S, Mac은 Command(⌘) + S를 사용해도 됩니다. 저장 중 표시가 끝나고 저장 완료 상태인지 확인합니다.
  3. 브라우저의 ‘다른 이름으로 저장’ 창이 뜨면 취소하고 Colab의 파일 → 저장을 선택합니다.
  4. 파일 → 다운로드 → .ipynb 다운로드를 누릅니다. 영문 메뉴는 File → Download → Download .ipynb입니다. .py 다운로드는 선택하지 않습니다.
  5. 브라우저의 다운로드 목록 또는 컴퓨터의 다운로드 폴더를 엽니다. 저장 위치를 직접 정했다면 그 폴더를 엽니다. 방금 받은 파일 이름과 받은 시각을 확인하세요.
  6. 제출할 파일이 .ipynb 형식이고 10MB 이하인지 확인합니다. .py 파일의 이름만 .ipynb로 바꾸면 안 됩니다. 고친 내용이 생기면 다시 실행·저장·다운로드하고 최신 파일을 제출합니다.

② 설문 답변 준비하기

어떤 자료를 썼고, 무엇을 바꾸었으며, 결과가 어떻게 달라졌는지 내 말로 적습니다. 각 질문에 맞는 짧은 세 문장 이상이면 3점입니다.

일곱 질문 · 시작말과 3문장 예시

질문에 맞게 짧은 문장 3개 이상을 쓰면 3점입니다. 2문장은 2점, 1문장은 1점, 미응답은 0점입니다. 긴 문장을 쓸 필요는 없습니다.

아래는 가상 평일 운동 시간(월~금 20·30·10·40·25분)의 예시입니다. 자신의 과제와 실제 경험으로 바꿉니다. 시작말은 도움말이며 각각의 배점 항목이 아닙니다.

1. 어떤 자료로 무엇을 만들어 보았나요?

문장 시작 도움말: 저는 ○○를 알아보고 싶었습니다. / ○○ 자료를 사용했습니다. / 실행해 보니 ○○를 알 수 있었습니다.

3문장 예시
저는 요일별 운동 시간을 비교하고 싶었습니다.
가상의 평일 운동 시간 다섯 개를 사용했습니다.

2. 만들면서 무엇이 어렵거나 고민되었나요?

문장 시작 도움말: ○○가 고민되었습니다. / 특히 ○○할 때 어려웠습니다. / 그 이유는 ○○입니다.

오류가 없었다면 주제나 자료를 고를 때의 고민을 써도 됩니다.

3문장 예시
하루 운동 시간을 얼마로 정할지 고민되었습니다.
특히 운동하는 날마다 다른 값을 넣는 것이 어려웠습니다.

문장 시작 도움말: ○○를 ○○로 바꾸었습니다. / ○○를 알아보고 싶었기 때문입니다. / 실행한 뒤 ○○가 달라졌습니다.

이미 바꾼 한 가지를 설명하세요. 별도 수정 기록은 제출하지 않습니다.

3문장 예시

평일에 운동할 시간을 비교해 보고 싶었기 때문입니다.
실행하니 축제 활동 대신 요일별 운동 시간을 보여 주는 표와 그래프가 나왔습니다.

4. 사용한 코드 한 부분은 어떤 일을 하나요?

문장 시작 도움말: 제가 고른 코드는 ○○입니다. / 이 코드는 ○○하는 데 쓰입니다. / 실행 결과는 ○○였습니다.

코드 한 줄을 골라도 됩니다. 코드 자체는 설명 문장 수에 포함하지 않습니다.

3문장 예시

3문장 예시
평균만 보면 날짜별 차이를 알기 어렵다는 점을 알았습니다.
평균은 25분이지만 수요일은 10분이고 목요일은 40분이었습니다.

  1. 과제 제목·학번·이름을 적습니다. 기본정보에는 점수가 없습니다.
  2. 과제 파일 문항의 파일 추가 → 업로드에서 기기의 파일을 선택합니다. 방금 다운로드한 .ipynb 파일 1개를 골라 업로드하고, 설문에 파일 이름이 나타나는지 확인합니다. 버튼 이름은 화면에 따라 조금 다를 수 있습니다.
  3. 일곱 질문을 읽고 내 작업과 경험을 씁니다. 각 문항은 질문에 맞는 완결 문장 3개 이상이면 3점입니다. 짧은 세 문장으로 써도 됩니다.
  4. 파일 이름·학번·이름·일곱 답변을 다시 확인하고 제출을 누릅니다. 업로드만으로 제출이 끝난 것은 아닙니다.
  5. ‘응답이 기록되었습니다’ 등 제출 완료 안내를 확인합니다. 응답 수정 링크가 보이면 보관하고, 마감 전 수정은 그 링크에서 고친 뒤 다시 제출합니다.

④ 제출 전후 마지막 확인

체크 표시는 이 안내를 보는 동안의 확인용이며 설문에 전송되지 않습니다.

제출한 뒤 고쳤다면 파일도 교체하세요. 다시 모두 실행 → 저장 → .ipynb 다시 다운로드 → 응답 수정 링크에서 이전 첨부 교체 → 다시 제출합니다. Colab 사본을 바꿔도 이전 첨부는 자동으로 바뀌지 않습니다.

예시 링크나 사진·영상이 열리지 않아요

Colab 링크가 열리지 않으면 기본 예시 파일을 받아 Colab의 파일 → 노트 열기 → 업로드로 엽니다. 학생용 ZIP은 압축을 모두 풀고 index.html을 여세요. images 폴더와 동영상 파일도 함께 있어야 합니다.

필요할 때만 · Windows·Mac 화면 캡처와 저장

프로그램을 따로 설치하지 않습니다. 오류를 선생님에게 보여 주거나 결과를 보관할 때 사용하세요. 화면 캡처는 추가 필수 제출물이 아니며, .ipynb 제출을 대신하지 않습니다.

Windows 10·11 — 캡처 도구

  1. 저장하고 싶은 계산·표·그래프 또는 오류 화면을 띄웁니다. Windows 로고 키 + Shift + S를 동시에 눌렀다 놓습니다.
  2. 사각형 캡처를 선택하고 필요한 부분을 마우스로 드래그합니다. 캡처 알림이 뜨면 눌러 캡처 도구(또는 캡처 및 스케치)에서 엽니다.
  3. 저장 아이콘 또는 Ctrl + S를 누릅니다. 바탕 화면처럼 찾기 쉬운 폴더, 파일 이름, PNG 형식을 선택하고 저장합니다. 예: 20501_홍길동_실행결과.png.
  4. 저장한 폴더에서 이미지 파일을 다시 열어 글자와 결과가 읽히는지 확인합니다. 복사만 된 상태로 끝내지 마세요. 알림을 놓쳤다면 시작 메뉴에서 ‘캡처 도구’를 검색해 열고 새로 만들기 → 영역 선택 → 저장을 진행합니다.

Mac — 기본 스크린샷 기능

  1. 저장하고 싶은 화면을 띄우고 Shift + Command(⌘) + 4를 동시에 눌렀다 놓습니다. 십자 모양 포인터로 필요한 부분을 드래그한 뒤 손을 뗍니다.
  2. 잠시 기다린 뒤 데스크탑(바탕 화면)에 생긴 스크린샷 파일을 찾습니다. 기본 저장 위치를 바꾼 적이 있다면 그 위치에 저장됩니다.
  3. 저장 위치를 확인하거나 바꾸려면 Shift + Command(⌘) + 5 → 옵션 → 다음으로 저장에서 데스크탑 또는 다른 위치를 고릅니다. ‘클립보드’ 대신 폴더를 선택하세요. PNG가 필요하고 포맷 선택이 보이면 SDR(높은 호환성)을 고릅니다.
  4. 저장한 파일을 더블클릭해 미리보기로 열고 내용이 읽히는지 확인합니다. 파일 이름을 알아보기 쉽게 바꾸세요. Control 키를 함께 누르면 파일 대신 클립보드로 복사될 수 있으므로 위 단축키만 사용합니다.

확인: 이미지 파일이 실제 폴더에 저장되어 다시 열리나요? 결과와 오류 글자가 잘 보이게 담고 불필요한 개인정보는 제외하세요.
