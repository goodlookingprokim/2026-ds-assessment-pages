# 1차 Orange 수행평가 · 한 장 안내

**자료 하나를 불러와 그래프 하나를 만들고, 발견한 내용을 자기 말로 설명합니다.**

대상: 고2 6·7·8·9반 · 평가: 11월 2~6일 · **제출 마감: 2026년 11월 6일까지**

1. **자료 하나 고르기** — 교사 자료 또는 내가 준비한 CSV·Excel 하나를 고릅니다.
2. **표와 그래프 만들기** — 자료를 열고 도구를 연결한 뒤 그래프에서 눈에 띄는 점 하나를 찾습니다.
3. **파일 1개 + 화면 2장 준비하기** — Orange 작업 파일(.ows), 전체 연결 화면, 그래프 결과 화면을 저장합니다.
4. **일곱 질문에 답하기** — 질문마다 내 작업에 맞는 짧은 문장 3개를 씁니다. 작성 가이드의 시작말을 참고하세요.
5. **설문으로 제출하기** — 답변과 필요한 파일을 모두 준비하고 최종 점검한 뒤 1회만 제출합니다. 개인 자료를 썼다면 원본도 올리고 제출 완료 안내를 확인합니다.

## 무엇을 쓰나요?

Q1. 어떤 결과물을 만들었나요? (3점)
Q2. 어떤 자료를 불러왔나요? (3점)
Q3. 어떤 도구를 연결했나요? (3점)
Q4. 그래프를 보고 무엇을 알았나요? (3점)
Q5. 이 활동이 나에게 어떻게 도움이 될까요? (3점)
Q6. 직접 해 보니 어땠나요? (3점)
Q7. 다음에 무엇을 보완하고 싶나요? (3점)

**총 30점:** 답변 21점 + 연결 상태 4점 + 분석 결과 5점.
각 질문에 맞는 완결된 문장 3개 이상 3점, 2개 2점, 1개 1점, 인정되는 문장 없음 0점입니다. 같은 뜻의 반복은 한 문장으로 봅니다. 시작말 세 개는 쓰기 도움이며 각각 1점짜리 필수 요소가 아닙니다.
