2. Orange 실습 따라 하기

위젯은 Orange의 작은 도구입니다. 이번 예시에서는 File(자료 열기), Data Table(표 보기), Scatter Plot(점으로 보는 그래프)을 씁니다. 목적에 맞는 다른 도구도 사용할 수 있습니다.

아래 화면은 11번 자료의 예시입니다. 다른 교사 주제를 골랐다면 그 CSV로 진행하세요. 개인 자료를 골랐다면 내 자료에 있는 숫자 항목으로 두 축을 고르고, 화면의 숫자나 열 이름이 예시와 달라도 괜찮습니다.

① 새 작업에 도구 세 개 놓기

  1. Orange의 New 또는 상단 메뉴 File → New로 새 작업을 엽니다.
  2. 왼쪽 Data에서 File과 Data Table을 작업 화면으로 끌어 놓습니다.
  3. 왼쪽 Visualize에서 Scatter Plot을 끌어 놓습니다. File은 왼쪽 가운데, Data Table은 오른쪽 위, Scatter Plot은 오른쪽 아래로 벌려 놓으세요. 두 연결선을 따로 볼 수 있습니다.

② 자료 열기

  1. 작업 화면의 File 도구를 두 번 누릅니다.
  2. 폴더 모양 버튼을 눌러 1차_수행평가 폴더 안의 내가 고른 CSV를 선택합니다. 따라 하기 예시는 11번 파일입니다.
  3. 이 예시는 자료 180개를 불러옵니다. 확인한 뒤 도구 창을 닫습니다.

CSV에는 시트 선택이 없습니다. 교사 Excel 원본을 사용한다면 ‘데이터’ 시트를 고릅니다.

③ File에서 두 곳으로 연결하기

왜 두 곳에 연결할까요? File은 CSV를 읽어 같은 자료를 두 도구로 보냅니다. Data Table에서는 행 수·열 이름·값과 빈칸을 확인해 자료를 제대로 읽었는지 살핍니다. Scatter Plot에서는 고른 숫자 열 두 개를 가로축·세로축에 놓아 점의 분포와 예외를 봅니다. 따라서 File → Data Table과 File → Scatter Plot을 각각 연결하세요. Data Table을 거쳐 Scatter Plot으로 잇는 순서가 아니라, 같은 원자료가 두 갈래로 갑니다.

File을 왼쪽 가운데에 두고 Data Table을 오른쪽 위, Scatter Plot을 오른쪽 아래에 두면 두 선의 출발점과 도착점이 겹치지 않아 확인하기 쉽습니다. 두 선에 Data가 표시되는지 살펴보세요. 위치 자체가 점수 기준은 아니며, 이 배치는 연결을 쉽게 확인하기 위한 예시입니다.

File → Data Table (표 보기) File → Scatter Plot (그래프 보기)
  1. File 오른쪽 연결점에서 Data Table 왼쪽 연결점까지 끌어서 놓습니다.
  2. 다시 File 오른쪽 연결점에서 Scatter Plot 왼쪽 연결점까지 끌어서 놓습니다.
  3. File에서 출발하는 선 두 개가 각각 Data Table과 Scatter Plot에 도착하는지 확인합니다. 두 위젯 사이에 연결선이 있어야 하는 것은 아닙니다.

④ 표 확인하기

Data Table을 두 번 누릅니다. 행은 사례 한 줄, 열은 표의 세로 항목입니다. 현재 11번 CSV는 180행·11열입니다. 이 화면 사진은 개정 전 8열 자료로 촬영했습니다. 새 열인 도움방식, 사전친숙도_점, 체감난이도_점도 찾아보세요.

현재 배포 CSV의 실제 Orange 화면

아래 두 사진은 11번 새 CSV를 File에서 다시 열어 확인한 화면입니다. 180 instances, 10 features, 1 meta attribute가 합쳐서 11열입니다. 영상과 다른 열 수가 나오면 이 사진과 내려받은 CSV를 기준으로 보세요.

⑤ 내가 고른 질문으로 그래프 만들고 읽기

14가지 질문 예시에서 하나를 고릅니다. 아래 사진의 참여·성과 축은 조작 시연용입니다. 자신의 질문에 맞는 숫자 열 두 개로 바꾸세요.

  1. 작업 화면으로 돌아와 Scatter Plot을 두 번 누릅니다.
  2. Axis x(가로축)는 내가 고른 질문의 첫 번째 숫자 열로 고릅니다.
  3. Axis y(세로축)는 내가 고른 질문의 두 번째 숫자 열로 고릅니다.
  4. Color(색상)는 질문에 맞게 집단, 활동유형, 도움방식 중에서 고릅니다.
  5. 점들이 보이면 모인 곳과 벗어난 점을 찾습니다. 관계가 뚜렷하지 않아도 그대로 적습니다.

여기까지 보이면 실습 성공! 표를 읽었고, 두 연결선이 있으며, 그래프의 점과 축 이름을 확인할 수 있습니다.

표의 빈칸이나 화면 아래 숫자가 궁금하다면

11번 자료의 참여·성과 열에는 빈칸이 있어 두 축을 고르면 180행 중 174개 점이 그려집니다. 다른 축을 고르면 표시되는 점 수가 달라질 수 있습니다. 빈칸을 0으로 채우거나 원본을 고칠 필요는 없습니다.

개정 전 화면의 7 features와 1 meta attribute는 당시 여덟 열입니다. 현재 CSV는 열이 11개입니다. Meta는 사례번호 같은 부가 정보라는 뜻입니다. 이 숫자와 특정 도구·축은 예시일 뿐, 개인 자료의 필수 조건이 아닙니다.

점들이 함께 높아 보이더라도 하나가 다른 하나의 원인이라고 단정하지 마세요. 교사 가상 자료의 결과를 실제 학생 전체의 사실로 쓰지 않습니다.

3. 작업 파일과 화면 저장하기
  1. 연결 화면 한 장: 사용한 도구와 연결선이 모두 보이게 캡처합니다.
  2. 결과 화면 한 장: 그래프와 축 이름, 사용한 설정이 함께 보이게 캡처합니다.
  3. 작업 파일 한 개: 상단 메뉴 File → Save로 학번_이름_11번.ows처럼 1차_수행평가 폴더에 저장합니다. 학번·이름·주제는 자신의 정보로 바꾸세요.
  4. 다시 열어 확인: 상단 메뉴 File → Open으로 방금 저장한 파일을 열고 연결과 결과가 남아 있는지 봅니다.

상단 File 메뉴는 저장·열기에 쓰고, 작업 화면의 File 도구는 데이터를 불러오는 데 씁니다.

화면 캡처를 실제 파일로 저장하기 · 프로그램 설치 불필요

클립보드에 복사된 것만으로는 제출할 파일이 아닙니다. 반드시 .png 파일이 생겼는지 확인하세요. 캡처 영역을 잘못 잡았다면 Esc로 취소하고 다시 합니다.

Windows · 기본 ‘캡처 도구’로 저장

  1. 연결 화면이 보이도록 한 뒤 Win + Shift + S를 누르고, 사용한 위젯과 모든 연결선이 보이는 영역을 끌어서 선택합니다.
  2. 화면 오른쪽 아래에 나타난 캡처 알림을 누르면 Windows 기본 캡처 도구가 열립니다.
  3. 다른 이름으로 저장 또는 Ctrl + S를 누르고, 1차_수행평가 폴더에 학번_이름_연결.png로 저장합니다.
  4. 결과 화면으로 돌아가 그래프·축 이름·사용한 설정이 보이게 다시 캡처하고 학번_이름_결과.png로 저장합니다.

캡처 알림을 놓쳤다면 Windows 기본 앱 그림판을 열고 Ctrl + V로 붙인 뒤 Ctrl + S로 PNG 파일을 저장해도 됩니다. 마이크로소프트 공식 캡처 도구 안내

Mac · 단축키로 바로 파일 저장

  1. 연결 화면이 보이도록 한 뒤 ⌘ + Shift + 4를 누르고, 사용한 위젯과 모든 연결선이 보이는 영역을 끌어서 선택합니다.
  2. 기본 설정에서는 캡처가 바탕 화면에 파일로 저장됩니다. Finder에서 파일 이름을 학번_이름_연결.png로 바꾸고 1차_수행평가 폴더로 옮깁니다.
  3. 결과 화면으로 돌아가 그래프·축 이름·사용한 설정이 보이게 다시 캡처하고 학번_이름_결과.png로 이름을 바꾸어 옮깁니다.

저장 위치를 바꾼 적이 있다면 ⌘ + Shift + 5 → 옵션에서 현재 저장 위치를 확인하거나 1차_수행평가 폴더로 지정하세요. 이미지가 HEIF로 저장된다면 형식에서 SDR(높은 호환성·PNG)를 선택한 뒤 다시 캡처합니다. 파일 이름 끝만 PNG로 바꾸지는 마세요. Apple 공식 스크린샷 안내

마지막 확인: 학번_이름_연결.png와 학번_이름_결과.png를 각각 다시 열어 글씨·축 이름·연결선이 읽히는지 확인합니다. 두 화면은 한 이미지로 합치지 말고 별도 파일로 저장합니다.

이제 파일 세 개가 있나요? 작업 파일 .ows 한 개와 화면 이미지 두 장입니다. .ows는 도구와 연결을 저장한 파일이며, 개인 자료를 썼다면 원본 CSV·Excel도 함께 보관하고 제출합니다.

5. 설문 제출과 마지막 확인
