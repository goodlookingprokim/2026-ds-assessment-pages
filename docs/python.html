  1. 예시를 Colab에 열기

    ★ 1. 내 자료 셀의 제목, 항목 이름, 이름, 숫자, 단위, 자료 설명을 내 주제에 맞게 바꿉니다. 이름과 숫자의 개수는 같게 맞춥니다.

    결과를 저장한 뒤 파일 → 다운로드 → .ipynb 다운로드를 선택합니다. Colab 링크나 .py 파일로 대신 내지 않습니다.
