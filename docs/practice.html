    파일 첨부 문항에서 파일 추가를 누릅니다. 업로드 → 찾아보기(Browse) 또는 파일 선택 버튼을 눌러 다운로드 폴더에서 본인의 학번과 이름으로 바꾼 연습 파일을 선택하세요. 예: 20601_홍길동_연습.txt. 파일을 고르면 업로드가 시작됩니다. 별도로 업로드 버튼이 보이면 누르세요. 업로드가 끝나고 설문지에 파일명이 나타날 때까지 기다립니다.

    • ② 파일명 확인: 첨부 파일 이름이 본인의 학번_이름_연습.txt 형식입니다.
    • ③ 파일 첨부 성공: 업로드가 끝나고 설문 문항에 첨부 파일 이름이 표시됩니다.
